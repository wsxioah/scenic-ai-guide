# 灵山AI数字人导览系统 — 部署说明文档

## 一、系统概述

灵山AI数字人导览系统是一套面向无锡灵山胜境景区的智能导览解决方案，包含三大子系统：

- **后端服务**：基于 FastAPI 的异步 Web 服务，集成 LLM 大模型对话、RAG 知识库检索、语音识别/合成、景物图像识别、个性化推荐引擎
- **移动端 App**：React Native (Expo) 跨平台应用，提供 AI 数字人语音对话、景区地图导航、拍照识景、景点浏览、个性化推荐等功能
- **管理后台**：Vue 3 + Ant Design 的 Web 管理端，提供数据看板、知识库管理、FAQ 管理、数字人配置、公告发布等功能

## 四、部署与启动步骤

### 步骤一：克隆/解压项目

```bash
# 如果是 zip 压缩包
unzip scenic-app.zip
cd scenic-app
```

### 步骤二：后端部署

```bash
# 1. 进入后端目录
cd backend

# 2. 创建虚拟环境（推荐）
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 配置环境变量（如需）
# 编辑 .env 文件，配置 LLM API Key：
# DEEPSEEK_API_KEY=your_key
# LLM_PROVIDER=deepseek

# 6. 初始化数据库（首次运行自动创建）
# SQLite 数据库文件将自动创建在 backend/ 目录下

# 7. 启动后端服务
python run.py
```

后端默认启动在 `http://0.0.0.0:8000`，终端显示：
```
Uvicorn running on http://0.0.0.0:8000
```

验证：浏览器打开 `http://localhost:8000/health`，应返回 `{"status":"healthy","database":"connected"}`

### 步骤三：移动端启动（开发模式）

```bash
# 1. 进入移动端目录
cd mobile

# 2. 安装依赖
npm install

# 3. 启动 Expo 开发服务器
npx expo start
```

手机安装 Expo Go 应用，扫码连接即可调试。

> **注意**：默认连接 `localhost:8000`。如果用真机调试且手机和开发机不在同一网络，需要在 `mobile/src/config.ts` 中将 `SERVER_HOST` 改为开发机的局域网 IP。

### 步骤四：管理后台启动

```bash
# 1. 进入管理后台目录
cd admin

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

管理后台默认启动在 `http://localhost:5173`，使用手机号 + 验证码 `0000` 登录。

### 步骤五：构建 Android APK

```bash
cd mobile
npx expo run:android
# 或云端构建
npx eas build --platform android
```

## 六、常见问题

**Q: 启动后端报 "ModuleNotFoundError"**
A: 确保已激活虚拟环境并执行 `pip install -r requirements.txt`

**Q: 景物识别模型加载失败**
A: 确认 `backend/models/recognition/best_model.pth` 文件存在（约 124MB），PyTorch 已正确安装

**Q: 地图无法加载**
A: 检查网络连接（需要访问百度地图 CDN），确认 `tools/map_inline_test.html` 存在，百度地图 API Key 未过期

**Q: LLM 对话无响应**
A: 检查 `.env` 中 API Key 配置是否正确，网络能否访问对应 LLM 服务商

**Q: 手机 App 连接不到后端**
A: 检查 `config.ts` 中的 `SERVER_HOST` 是否为开发机 IP，手机和开发机是否在同一网络，防火墙是否放行 8000 端口
