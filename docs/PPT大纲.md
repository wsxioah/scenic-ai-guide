## 第8页：技术亮点 — 句级流式 TTS

**传统方案**：等待全文 → 全量合成 → 播放（首播延迟 8-15秒）

**本方案**：LLM 逐字输出 → 实时检测句子边界 → 逐句异步合成 → 有序交付

```
LLM:  "灵山大佛高88米。"→[合成句1]→→播放句1
      "于1997年落成。"  →[合成句2]→→→→播放句2
      "是世界最高..."    →[合成句3]→→→→→→播放句3
```

首句播放延迟降至 **< 1.5 秒**

## 第9页：技术亮点 — 双条件图像过滤

**问题**：Softmax 强制 100% 分配 → 键盘照也能 43% 置信度

**解决**：双条件校验
- 条件1：Top-1 置信度 ≥ 50%
- 条件2：Top-1 与 Top-2 差距 ≥ 15pp

**效果**：
| 图片类型 | 过滤前 | 过滤后 |
|---------|--------|--------|
| 灵山景点 | 正确识别 | 正确识别 |
| 键盘/人物 | 43% 误判 | 正确拦截 |

## 第10页：技术亮点 — 140K 数据驱动推荐

**四层混合推荐策略：**

| 层级 | 方法 | 适用场景 |
|------|------|---------|
| 热门推荐 | 访问量 + 满意度排序 | 所有游客 |
| 画像推荐 | 年龄/性别/预算匹配 | 首次使用 |
| 协同过滤 | 相似游客偏好 | 有浏览记录 |
| 个性化 | 对话关键词 + 收藏 | 登录用户 |

**数据来源**：14 万条真实游客行为记录（年龄、性别、消费、满意度、停留时长等）
