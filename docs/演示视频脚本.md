## 制作建议

1. **画面录制**：使用手机录屏（移动端）+ OBS 录屏（管理后台），避免摄像头对着屏幕翻拍
2. **旁白录音**：使用专业麦克风录制，确保声音清晰；也可使用 Edge-TTS 生成
3. **字幕**：全程添加中文字幕，关键数据（延迟时间、准确率等）用加粗或高亮标注
4. **剪辑节奏**：对话和地图部分是重头戏，给足展示时间；管理后台可适当加速
5. **BGM**：选用舒缓的国风背景音乐（如古筝、笛子），音量适中不压旁白
